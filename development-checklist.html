Suggested Build Breakdown Development Notes

Per Module Definition of Done

  • Module folder exists in the correct year and term.
  • All 17 lectures have matching AI-generated HTML note pages.
  • Exam question files are stored in a dedicated `exam-qs` location.
  • Original-source assessment material is retained, not only rewritten output.
  • Links from the main Study Hub page point to the correct module assets.

Recommended Naming Pattern

  • `/year 1/sem 2/mod1/lecture1.html` through `lecture17.html`
  • If one HTML covers two lectures, record both lectures as complete and note the shared file.
  • `/year 1/sem 2/mod1/exam-qs/mcq-drill.html` and `written-answers.html`
  • `/year 1/sem 2/mod1/exam-qs/walkthrough-2022-23.html` and `walkthrough-2021-22.html`
  • Keep checklist paths aligned with the actual on-disk structure.
