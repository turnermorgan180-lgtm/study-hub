Question 1

Basic probability

Full seminar question

A jar contains 49 green marbles and 73 blue ones. What is P(Green)?

Model answerSeminar

There are 122 marbles in total, so [[math:P(\text{Green})=\frac{49}{122}=0.402]] approximately.

Question 2

Conditional probability

Full seminar question

A jar contains 77 marbles that are just green, 94 just blue, and 90 both green and blue. What is P(Green|Blue)?

Model answerSeminar

Given blue means restricting attention to blue marbles: just blue plus both equals 184. Of those, 90 are also green, so [[math:P(\text{Green}\mid\text{Blue})=\frac{90}{184}=0.489]] approximately.

Question 3

Joint probability from conditional information

Full seminar question

If [[math:P(A)=0.96]], [[math:P(B)=0.32]] and [[math:P(A\mid B)=0.53]], what is P(A and B)?

Model answerSeminar

Use [[math:P(A\mid B)=\frac{P(A\cap B)}{P(B)}]]. Therefore P(A and B) = 0.53 x 0.32 = 0.1696.

Question 4

Probability from table

Full seminar question

Given the survey table in Question 4, calculate P(Tea).

Model answerSeminar

Add all tea drinkers and divide by the total sample. The tea total is 69 + 93 + 55 = 217 and the grand total is 533, so [[math:P(\text{Tea})=\frac{217}{533}=0.407]] approximately.

Question 5

Conditional probability from table

Full seminar question

Given the survey table in Question 5, calculate P(UG|Tea).

Model answerSeminar

Tea drinkers total 65 + 5 + 56 = 126. Undergraduate tea drinkers are 65, so P(UG|Tea) = 65 / 126 = 0.516 approximately.

Question 6

Disease testing

Full seminar question

Prevalence is 23%, sensitivity is 77%, and specificity is 55%. If a person tests positive, what is the probability they actually have the disease?

Model answerSeminar

Apply Bayes’ rule. True-positive probability is 0.23 x 0.77 = 0.1771. False-positive probability is 0.77 x 0.45 = 0.3465. Therefore P(Disease|Positive) = 0.1771 / (0.1771 + 0.3465) = 0.338 approximately.

Question 7

Expected payoff

Full seminar question

The payoffs are 91, 29, and 29 with probabilities 0.09, 0.27, and the remainder. What is the expected payoff?

Model answerSeminar

The third probability is 0.64. Expected payoff = 91(0.09) + 29(0.27) + 29(0.64) = 34.58.

Question 8

Permutations

Full seminar question

If five people are chosen from 51 and each has a different job, how many ways are there to assign the jobs?

Model answerSeminar

Because the jobs are distinct, order matters. The number of ways is 51P5 = 51 x 50 x 49 x 48 x 47 = 281,887,200.
