Core Quant Methods Sheet

A condensed working sheet for descriptive statistics, probability, distributions, confidence intervals, hypothesis tests, chi-squared, ANOVA, regression and SPSS test selection.

Exam use: write the name of the method first, then the formula or SPSS procedure, then the substituted calculation or Sig. value, then one interpretation sentence in plain business language.

Descriptive Statistics

Mean = Σx / nSample variance = Σ(x - x̄)^2 / (n - 1)Sample SD = √s^2IQR = Q3 - Q1
  • Use the sample formulas unless the question clearly gives a population.
  • Boxplots rely on five-number summary plus IQR interpretation.

Probability

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)P(A | B) = P(A ∩ B) / P(B)P(A ∩ B) = P(A | B)P(B)P(A | B) = [P(B | A)P(A)] / P(B)
  • Bayes questions usually hinge on computing the denominator correctly.
  • Use complements for “at least one” or “none”.

Expected Value and Distributions

E(X) = Σ[xp(x)]Var(X) = Σ[(x - μ)^2 p(x)]Bernoulli: mean = p, variance = p(1 - p)Binomial: P(X = r) = nCr p^r (1-p)^(n-r)
  • Identify whether the setup is Bernoulli, binomial, or normal before calculating.

Standardisation and Normal

z = (x - μ) / σ
  • Z-scores compare observations across different scales.
  • Use tables carefully and keep track of left-tail versus right-tail probability.

Confidence Intervals

CI = x̄ ± critical value × SESE(mean) = s / √n
  • Use z or t depending on the context and what the module expects.
  • Higher confidence widens the interval; larger n narrows it.

Hypothesis Testing

Test statistic = (estimate - hypothesised value) / SESPSS decision: Sig. < 0.05 => reject H0
  • State H0 and H1 explicitly.
  • Choose one-tailed or two-tailed correctly.
  • Decision is based on p-value or critical value, then interpret in context.

Chi-Squared and ANOVA

χ² = Σ[(O - E)^2 / E]ANOVA: F = MST / MSE
  • Chi-squared needs observed and expected counts.
  • ANOVA compares group means using variance between and within groups.

Regression

ŷ = a + bxr = covariance / (σxσy)R² = explained variation / total variation
  • Slope shows the expected change in y for a one-unit rise in x.
  • Correlation is not causation.

SPSS Test Selection

One-Sample T Test: scale mean vs fixed valuePaired-Samples T Test: two scale variables, same casesIndependent-Samples T Test: scale outcome, two groupsOne-Way ANOVA: scale outcome, 2+ groupsCrosstabs + Chi-square: two categorical variables
  • Use Compare Means for t-tests and ANOVA.
  • Use Nonparametric Tests or Crosstabs for categorical frequency and association tests.
  • If expected chi-squared counts are below 5, flag reliability concerns.
