Exam Equation Sheet

The full exam-facing equation set for time value of money, bonds, equity, returns, portfolios and CAPM, with a variable key beside each group. Use it with the lecture notes and the calculation drill, not as a substitute for method.

Exam use: write the formula, define the inputs, substitute cleanly, then finish with an interpretation in pounds, pence, percent, yield, or risk as appropriate.

Time Value

Single cash flows

[[display:FV=PV(1+r)^n]][[display:PV=\frac{FV}{(1+r)^n}]][[display:FV=PV e^{rt}]][[display:PV=FV e^{-rt}]][[display:r=\frac{\ln(FV/PV)}{t}]]
Variable key

PV = present value today; FV = future value; r = interest or discount rate per period; n = number of discrete periods; e = base of natural logs; t = time in years for continuous compounding.

Multiple Cash Flows

General present value

[[display:PV=\sum_{t=1}^{n}\frac{C_t}{(1+r)^t}]]

Annuities

[[display:PV=C\frac{1-(1+r)^{-n}}{r}]][[display:FV=C\frac{(1+r)^n-1}{r}]][[display:PV_{due}=PV_{ordinary}(1+r)]]
Variable key

Ct = cash flow at time t; C = constant payment; r = rate per payment period; n = number of payments; PVdue = value when payments start immediately.

Perpetuities and Loan Balances

Perpetuities

[[display:PV=\frac{C}{r}]][[display:PV=\frac{C_1}{r-g}]]

Mortgage or loan balance

[[display:B_k=C\frac{1-(1+r)^{-(N-k)}}{r}]]
Outstanding balance after k payments = PV of remaining payments.
Variable key

C = constant payment; C1 = first cash flow next period; r = discount rate; g = constant growth rate; Bk = balance after k payments; N = total payments; N-k = remaining payments.

Interest Rates

Effective annual rate

[[display:EAR=\left(1+\frac{APR}{m}\right)^m-1]][[display:APR=m\left[(1+EAR)^{1/m}-1\right] ]]

Holding-period return

[[display:HPR=\frac{\text{Ending value}-\text{Beginning value}+\text{Income}}{\text{Beginning value}}]]
Variable key

EAR = effective annual rate; APR = stated annual proportional rate; m = compounding periods per year; HPR = return over the holding period; income = coupon, dividend, or other cash income.

Bonds

Zero-coupon and coupon bond prices

[[display:P=\frac{F}{(1+y)^n}]][[display:P=\sum_{t=1}^{n}\frac{C}{(1+y)^t}+\frac{F}{(1+y)^n}]]

Bond return measures

[[display:\text{Current yield}=\frac{\text{Annual coupon}}{\text{Current price}}]][[display:HPR=\frac{C+P_1-P_0}{P_0}]]
Variable key

P = bond price; F = face or nominal value; C = coupon payment per period; y = yield to maturity per period; n = periods to maturity; P0 = opening price; P1 = ending price.

Convertible Bonds

Conversion terms

[[display:\text{Conversion value}=\text{number of shares}\times\text{share price}]][[display:\text{Conversion price}=\frac{\text{Nominal value}}{\text{number of shares}}]][[display:\text{Conversion premium}=\text{convertible bond price}-\text{conversion value}]][[display:\text{Minimum value}=\max(\text{straight bond value},\text{conversion value})]]
Variable key

Conversion value = equity value received if converted now; conversion price = implied price paid per share; conversion premium = extra paid above immediate conversion value; straight bond value = value if conversion option is ignored.

Equity Valuation

One-period and constant-growth DDM

[[display:P_0=\frac{D_1+P_1}{1+r}]][[display:P_0=\frac{D_1}{r-g}]][[display:r=\frac{D_1}{P_0}+g]]

Yield decomposition

[[display:\text{Dividend yield}=\frac{D_1}{P_0}]][[display:\text{Capital gain rate}=\frac{P_1-P_0}{P_0}]]
Variable key

P0 = current share price; P1 = expected future price; D1 = next dividend; r = required return on equity; g = constant dividend and earnings growth rate.

Growth and PVGO

Growth from reinvestment

[[display:g=b\times ROE]][[display:b=1-\text{payout ratio}]]

No-growth value and growth opportunities

[[display:P_{\text{no growth}}=\frac{EPS_1}{r}]][[display:PVGO=P_0-\frac{EPS_1}{r}]]

Multi-stage horizon value

[[display:P_H=\frac{D_{H+1}}{r-g}]]
Variable key

b = retention or plowback ratio; ROE = return on equity; EPS1 = next period earnings per share; PVGO = present value of growth opportunities; H = horizon date before stable growth begins.

Preference Shares and P/E

Preference share valuation

[[display:P_0=\frac{D_p}{r_p}]]

Price-earnings ratio

[[display:P/E=\frac{\text{share price}}{\text{earnings per share}}]][[display:EPS=\frac{\text{dividend per share}}{\text{payout ratio}}]]
Variable key

Dp = fixed preference dividend; rp = required return on preference shares; EPS = earnings per share; payout ratio = dividends divided by earnings.

Returns

Arithmetic and geometric returns

[[display:\bar{R}=\frac{R_1+R_2+\cdots+R_n}{n}]][[display:\bar{R}_G=\left[(1+R_1)(1+R_2)\cdots(1+R_n)\right]^{1/n}-1 ]]

Blume adjustment

[[display:R_{Blume}=\frac{N-T}{N-1}\bar{R}_A+\frac{T-1}{N-1}\bar{R}_G]]
Variable key

Ri = return in period i; n = number of periods; A = arithmetic average; G = geometric average; N = historical sample length; T = forecast horizon.

Expected Return and Risk

Scenario analysis

[[display:E(R)=\sum_{i=1}^{n}p_iR_i]][[display:Var(R)=\sum_{i=1}^{n}p_i\left[R_i-E(R)\right]^2 ]][[display:\sigma=\sqrt{Var(R)}]]

Historical sample risk

[[display:s^2=\frac{\sum(R_t-\bar{R})^2}{n-1}]]
Variable key

pi = probability of state i; Ri = return in state i; E(R) = expected return; Var(R) = variance; σ = standard deviation; R̄ = sample mean return; s2 = sample variance.

Portfolios

Portfolio return and variance

[[display:E(R_p)=w_AE(R_A)+w_BE(R_B)]][[display:\sigma_p^2=w_A^2\sigma_A^2+w_B^2\sigma_B^2+2w_Aw_B\sigma_A\sigma_B\rho_{AB}]][[display:Cov_{AB}=\rho_{AB}\sigma_A\sigma_B]]
Variable key

wA, wB = portfolio weights; E(RA), E(RB) = expected returns; σA, σB = standard deviations; ρAB = correlation; CovAB = covariance.

Beta and CAPM

Beta

[[display:\beta_i=\frac{Cov(R_i,R_m)}{\sigma_m^2}]][[display:\beta_i=\rho_{im}\frac{\sigma_i}{\sigma_m}]][[display:\beta_p=\sum w_i\beta_i]]

CAPM / Security Market Line

[[display:E(R_i)=R_f+\beta_i\left[E(R_m)-R_f\right] ]]
Variable key

βi = asset beta; βp = portfolio beta; Rf = risk-free rate; E(Rm) = expected market return; E(Rm) - Rf = market risk premium; ρim = correlation with market.
