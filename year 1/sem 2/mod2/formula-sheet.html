Core Formula Sheet

A compact exam-facing sheet for time value of money, bonds, equity, returns, portfolios and CAPM. Use it with the lecture notes and the calculation drill, not as a substitute for method.

Exam use: write the formula, define the inputs, substitute cleanly, then finish with an interpretation in pounds, pence, percent, yield, or risk as appropriate.

Time Value

Single cash flow

FV = PV(1 + r)^nPV = FV / (1 + r)^n
  • Match the interest rate to the time unit.
  • Use monthly rates for monthly annuities and semiannual rates for semiannual bonds.

Annuities

PV = C[(1 - (1 + r)^-n) / r]FV = C[((1 + r)^n - 1) / r]
  • Ordinary annuity assumes end-of-period payments.
  • For an annuity due, multiply by (1 + r).

Bonds

Coupon bond price

P = Σ[C / (1 + y)^t] + F / (1 + y)^n
  • Premium bond: coupon rate > yield.
  • Discount bond: coupon rate < yield.
  • Yield and price move inversely.

Holding-period return

HPR = (Coupon + P1 - P0) / P0

Current yield

Current yield = Annual coupon / Current price

Equity

Dividend discount logic

P0 = (D1 + P1) / (1 + r)P0 = D1 / (r - g)
  • The Gordon model needs r > g.
  • D1 is next period’s dividend, not today’s dividend.

Dividend yield

Dividend yield = D1 / P0

Price-earnings ratio

P/E = Share price / Earnings per share

Growth Value

No-growth benchmark

P(no growth) = EPS1 / r

Present value of growth opportunities

PVGO = P0 - [EPS1 / r]
  • Use payout ratio to move between dividends and earnings.
  • PVGO isolates the value of future reinvestment.

Risk and Return

Expected return

E(R) = Σ[p_i × R_i]

Variance and standard deviation

Var(R) = Σ[p_i × (R_i - E(R))^2]SD = √Var(R)
  • State whether returns are percentages or decimals.
  • Risk-averse investors care about dispersion, not just mean return.

Portfolios and CAPM

Two-asset return

E(Rp) = wA E(RA) + wB E(RB)

Two-asset variance

Var(Rp) = wA^2σA^2 + wB^2σB^2 + 2wAwBσAσBρAB

CAPM

E(Ri) = Rf + βi[E(Rm) - Rf]
  • Diversification removes firm-specific risk, not market risk.
  • Beta measures sensitivity to market movements.
