01

Page Purpose and Hierarchy

This template is designed for long-form revision content. The structure deliberately starts with orientation, moves into clearly segmented teaching blocks, and finishes with exam-style material. That sequencing makes the page feel authored rather than dumped from notes.

Template rule

Every lecture page should explain, not just store information. The layout works best when each section moves from concept, to mechanism, to implication, to exam use.

Visually, the hierarchy depends on three layers: elegant serif headings for structure, plain sans-serif body copy for readability, and uppercase monospace labels for metadata and small guidance markers.

Stakeholder takeaway

The page should feel premium and academic, but still practical. It is closer to a designed revision handout than a generic website article.

02

Key Term Card System

The term-grid pattern provides a fast, scannable entry point at the top of a lecture. It works well for vocabulary, formulas, frameworks, or core distinctions that students need to lock in early.

Why this component matters

  • It breaks up the top of a long page without feeling decorative.
  • It gives immediate value before the user reaches denser sections.
  • It creates a reusable content pattern across lectures.
Common mistake

Do not overload these cards with mini-paragraphs. They work because each definition stays compact, clear, and easy to scan.

03

Definition and Evaluation Blocks

The semantic callout system is one of the strongest parts of the page language. Different colors signal different kinds of thinking without needing heavy iconography or complex layout changes.

Component Use Effect on reading
Definition box Formula, rule, or memory anchor Creates a clear takeaway moment
Evaluation box Judgement, nuance, limitations Signals higher-order thinking
Mistake box Warnings about weak answers Sharpens exam discipline
Recommended logic
  • Gold boxes capture what must be remembered precisely.
  • Teal boxes show interpretation, evaluation, or judgement.
  • Red boxes protect against predictable weak answers.
04

Tables and Explanatory Logic

Tables are used sparingly to compare concepts or compress structured information. They are not meant to become spreadsheet-like data blocks. The tone stays academic and lightweight.

Presentation principle

Use tables when comparison adds clarity. If a paragraph explains the idea better, prefer the paragraph.

The accompanying logic box is useful when a section needs a short list of exam-ready explanatory steps, especially for diagrams, frameworks, or analytical sequences.

05

Step-by-Step Process Layout

The numbered step pattern is designed for causal chains and worked explanations. It visually slows the reader down in a useful way, making process explanation easier to follow.

1
Introduce the trigger: state the event, problem, or starting condition clearly.
2
Explain the mechanism: show what changes and why it changes.
3
State the outcome: identify the final effect on output, welfare, prices, behaviour, or decision-making.
4
Link to exam use: convert the chain into the exact kind of explanation a student would write under pressure.
Why it works

This component turns abstract reasoning into a controlled sequence. It is especially effective in economics, law, policy, and any note format built around cause and effect.

06

Exam Question Presentation

The final section demonstrates how revision notes translate into exam-facing blocks. The dark header creates a clean visual break and makes the question card feel deliberate rather than improvised.

Section B style preview 8 marks

Explain how this template supports both readability and exam preparation.

Model answer

This template supports readability by using a narrow content width, strong typographic hierarchy, generous spacing, and semantic callout components that break dense information into manageable blocks. Serif headings give sections authority, while sans-serif body text keeps long reading comfortable.

It supports exam preparation because the page structure consistently moves from concept to explanation to evaluation. Components such as mistake boxes, logic boxes, and exam question cards help students translate notes into stronger written answers. The result is a page that is not only attractive, but instructionally useful.
